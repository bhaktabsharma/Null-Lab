# NULLLAB Vulnerability Coverage Matrix

Generated by `npm run coverage:matrix`. 119 lab(s) implemented across 12 of 12 vulnerability families.

A subcategory is marked **Implemented** only because a real lab manifest exists for it on disk.
The test/verification columns reflect `docs/lab-verification-status.json` — hand-maintained, except the proxy flag
(see below), which is generated from a real run. Nothing here is asserted without a corresponding entry.

**"Verified (raw HTTP client)"** means the lab's exploit was driven end-to-end by an automated HTTP client
(plain requests with a cookie jar) against the real spawned target.

**"Verified via local proxy harness"** means the same exploit test was re-run with every learner-side request
routed through a local intercepting-style forward proxy (`npm run test:proxy`, see `tests/integration/proxy.ts`) and the
control plane's server-side verifier still recorded the solve, within a single test file. This flag is generated from
that run (`npm run proxy:status`), not typed by hand. It is **not** a Burp Suite result: the harness is a generic
HTTP/1.1 forward proxy that mimics Burp's plain-HTTP listener. No lab has been tested in Burp itself, and the
labs triggered in a real browser (XSS, clickjacking, prototype-pollution admin bot) are deliberately not counted,
because that browser is not routed through the harness.
